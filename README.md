# Tiny Recursive Model for Sudoku

Минимальная учебная реализация идеи TRM (Tiny Recursive Model): одна маленькая
нейронная сеть несколько раз уточняет скрытое состояние одной и той же доски.
Репозиторий не претендует на точное воспроизведение статьи. Его цель — показать
главную идею на задаче, которую легко проверить: обычных судоку 9×9.

Модель получает цифры и пустые клетки, собирает контекст строки, столбца и блока
3×3 и повторяет один и тот же `RefinementBlock`. После обучения доступны два
режима проверки:

- `neural`: прямой ответ сети; отчёт показывает точность клеток и долю полностью
  решённых досок;
- `guided`: точный поиск с возвратом, в котором логиты сети задают порядок цифр.
  Здесь корректность гарантирует поиск, а модель только направляет его.

## Быстрый запуск

Нужен Python 3.10+ и PyTorch.

```powershell
python -m pip install -e ".[dev]"
python -m trm_sudoku.demo
python -m trm_sudoku.benchmark
python -m pytest -q
```

`demo` обучает модель на небольшом детерминированном наборе автоматически
сгенерированных корректных досок и решает классический пример. Весовые файлы в
Git не требуются: seed, генератор данных и параметры запуска зафиксированы.

## Что здесь является TRM

В `TinyRecursiveModel` один блок с общими весами вызывается `steps` раз. Это
буквально рекурсивное уточнение представления при фиксированном числе параметров.
В отличие от полной исследовательской архитектуры здесь нет adaptive computation
time и сложной схемы глубокого надзора. Такое упрощение помещается примерно в
сто строк и подходит для разбора на втором курсе.

## Реальные проверки

В `trm_sudoku/puzzles.py` лежат известные корректные судоку 9×9 с решениями.
Бенчмарк проверяет сохранение исходных подсказок, допустимость строк, столбцов и
блоков, точное совпадение с решением, число узлов поиска и время. Сгенерированные
доски используются для обучения, а фиксированные примеры — только для проверки.

Результаты нельзя выдавать за качество полного TRM или ARC-AGI: это маленький
воспроизводимый стенд для одной задачи.
